# Phase 5 — Synthetic Route-Time Prediction Experiment

## Scope and Target

The target is `estimated_travel_time_s`: the scenario-estimated time for one person to traverse one specified route. It is not group bottleneck clearance time, total campus evacuation time, or a measured real-world outcome.

Training labels are generated by the existing Phase 4 equation and explicit scenario inputs. The Random Forest therefore learns an approximation to those assumptions; synthetic holdout performance does not establish real evacuation-time accuracy.

## Features and Units

| Feature | Unit / definition |
|---|---|
| `total_distance_m` | Sum of route edge lengths, metres. |
| `base_walking_speed_mps` | Explicit scenario walking speed, metres per second. |
| `route_edge_count` | Number of edge segments. |
| `distance_weighted_congestion_m` | Sum of `edge distance_m × congestion_score`; metres weighted by a dimensionless score. |
| `mean_congestion_score` | Mean of Phase 4 scenario scores, dimensionless `[0,1]`; missing/stale samples contribute the explicit unadjusted value 0 while coverage is separately exposed. |
| `peak_congestion_score` | Maximum scenario score, dimensionless `[0,1]`. |
| `over_capacity_edge_count` | Number of scenario segments with occupancy greater than supplied capacity. |
| `valid_measurement_edge_fraction` | Fraction of route segments with a fresh, timestamped scenario sample. |

Occupancy and capacity are explicit scenario counts in people; they are not read from Supabase as measured values. Freshness follows the Phase 4 15-minute rule. Blocked paths are rejected before inference.

## Synthetic Generation

`ai/prediction/train_experiment.py` creates data deterministically using seed `20261010`. It generates 300 distinct route templates and four occupancy scenarios per template (1,200 rows total): 1–8 edges per route, 3–35 m per edge, base speed 0.7–1.8 m/s, nominal capacity 20–160 people per edge, and occupancy between 0% and 150% of capacity. Labels are sums of the current Phase 4 edge-time equation.

The split uses `GroupShuffleSplit(test_size=0.2)` grouped by route-template ID so variations of one route template cannot appear in both train and test partitions. The checked-in script writes a dataset CSV, evaluation JSON, and joblib estimator to `ai/prediction/artifacts/`; this directory is ignored by Git. Regenerate with:

```powershell
python ai/prediction/train_experiment.py
```

## Evaluation

Experiment run with scikit-learn `1.7.2`, seed `20261010`, 250 trees, `min_samples_leaf=2`, and 1,200 generated rows:

| Model | MAE (s) | RMSE (s) | R² |
|---|---:|---:|---:|
| Analytical Phase 4 baseline | 0.0000 | 0.0000 | 1.0000 |
| Random Forest | 5.8345 | 8.3795 | 0.9910 |

The baseline is exact because synthetic labels are produced by the same analytical formula. The Random Forest did **not** outperform it. Its high R² is not evidence of real-world predictive validity and is especially uninformative for a deterministic synthetic target.

## Inference

The offline artifact is `ai/prediction/artifacts/evacuation_time_rf.joblib`, version `synthetic-route-time-rf-v1`. Training is never performed in a request. `POST /api/campuses/{campus_id}/routes/predicted-time` accepts a specified route (`path_node_ids`, matching `edge_ids`), explicit base speed, and optional per-edge scenario occupancy/capacity samples.

Before prediction, the service reloads the current graph and emergency conditions, verifies each exact directed edge step, and rejects routes containing currently blocked nodes or edges. It derives features using the same shared Phase 4 feature extractor and loads the artifact for inference. The response reports prediction seconds, route distance, model version, synthetic training-data type, features, measurement statuses, and validation limitation. Missing artifact returns service unavailable; there is no runtime training or model cache.

## Limitations

- Supabase has no live occupancy observations; current condition tables contain no rows.
- Existing persisted capacity, density, congestion, and speed fields lack documented units/semantics and are not used as calibrated measurements.
- Model labels are formula-generated synthetic values, not independent observations.
- The prediction is for one person on a supplied route; it does not simulate groups, bottlenecks, or total evacuation clearance.
- A low predicted time is not a safety assessment. The model is not validated for actual evacuation decisions.
